# Verification report

Owner: tester. Status: not run.

## Tested state

Record revision or relevant file state, environment, running services, interface
version, fixtures, and known tool limitations. Identify mocked dependencies.

## Execution evidence

| Check | Working directory and exact command or manual steps | Expected result | Actual outcome / evidence | Status |
| --- | --- | --- | --- | --- |

Allowed statuses: passed, failed, blocked, not run. Empty tables mean no tests
have been run. Planned commands are not execution evidence.

## Defects and retesting

For each defect: ID, severity, criterion, reproduction, expected versus actual,
evidence, responsible developer, and retest outcome. Mark evidence stale when
affected code changes.
